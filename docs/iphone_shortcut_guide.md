# 「宥芯同步」iPhone 捷徑製作步驟（James 做一次）

做好後分享成 iCloud 連結貼給 Claude，Claude 會把它放進 App（`liff/src/config.js` 的 `HEALTH_SHORTCUT_URL`）。
以下動作名稱以 iOS 17／18 繁中介面為準，版本不同時名稱可能略有差異。

## 事前準備

1. 先部署上線，並把你自己設成會員（後台填會員編號）。
2. 在 App「訓練」頁按「開始設定」，複製你的同步碼，做捷徑時測試用。
3. 到 Supabase 後台 → Project Settings → API Keys，複製 **anon（或 publishable）金鑰**。這把金鑰本來就放在網頁裡，是公開的，不是密碼。**不要複製 service_role／secret 那把。**

## 建立捷徑（名稱：宥芯同步）

打開「捷徑」App → 右上角「＋」，依序加入以下動作：

| # | 動作 | 設定 |
|---|------|------|
| 1 | 文字 | 貼上你的同步碼 → 把這個動作重新命名或記住它叫「同步碼」 |
| 2 | 重複 | 2 次（第 1 次＝今天，第 2 次＝昨天） |
| 3 | 計算 | 「重複索引」−「1」 |
| 4 | 調整日期 | 「目前日期」減去「計算結果」天 |
| 5 | 調整日期 | 對上一步的日期選「取得一天的開始」→ 設為變數 **起** |
| 6 | 調整日期 | 「起」加上 1 天 → 設為變數 **迄** |
| 7 | 尋找健康樣本 | 類型「步數」，開始日期「介於」起 和 迄 |
| 8 | 計算統計資料 | 「總和」，輸入第 7 步 → 設為變數 **步數** |
| 9 | 尋找健康樣本 | 類型「活動能量」，開始日期「介於」起 和 迄 |
| 10 | 計算統計資料 | 「總和」，輸入第 9 步 → 設為變數 **活動** |
| 11 | 尋找健康樣本 | 類型「靜止心率」，開始日期「介於」起 和 迄，排序「開始日期」最新優先，限制 1 → 設為變數 **心率** |
| 12 | 格式化日期 | 第 4 步的日期，格式「自訂」：`yyyy-MM-dd` → 設為變數 **日** |
| 13 | 取得 URL 的內容 | 見下方 |
| 14 | 結束重複 | （第 2 步自動產生） |
| 15 | 顯示通知（選用） | 「宥芯同步完成」 |

### 第 13 步：取得 URL 的內容

- URL：`https://hdwxdghjkikivtrqgcee.supabase.co/rest/v1/rpc/health_sync`
- 方法：**POST**
- 標頭：
  - `apikey`：貼上 anon 金鑰
  - `Content-Type`：`application/json`
- 要求內容：**JSON**，新增 5 個欄位，類型都選「文字」：

| 鍵 | 值 |
|----|----|
| `p_token` | 第 1 步「同步碼」 |
| `p_day` | 變數「日」 |
| `p_steps` | 變數「步數」 |
| `p_active_kcal` | 變數「活動」 |
| `p_rhr` | 變數「心率」 |

> 沒有資料時捷徑會傳空白或 0，App 會自動略過，不會出錯。數字帶單位或逗號（「8,123」「62 次/分」）也會自動轉成數字。

## 測試

1. 手動執行一次捷徑，第一次會跳出健康資料權限，把步數、活動能量、靜止心率都打開。
2. 成功時第 13 步會回傳 `{"ok": true, "day": "…", "saved": [...]}`。
   - `saved` 有 `rhr` 表示心率存了；有 `activity` 表示步數／熱量存了（要先開放熱量功能）。
   - 出錯會看到中文訊息，例如「同步碼無效」。
3. 回 App 檢查：
   - 安靜心跳旁邊應該出現「iPhone 自動」。
   - 後台客人頁會顯示「iPhone 自動同步：最後 11/28 22:01」。
4. **步數請和「健康」App 的數字比對一下**：同時戴 Apple Watch 和帶 iPhone 時，原始樣本相加有可能重複計算。如果捷徑的數字明顯比「健康」App 大，在第 7、9 步加篩選條件「來源」只選 Apple Watch（或只選 iPhone），然後告訴我結果。

## 設成「匯入問題」並分享

1. 捷徑右上角「ⓘ」→「設定」→「匯入問題」→「加入問題」→ 選第 1 步的文字，問題寫「請貼上 App 裡的同步碼」。
2. **把第 1 步的文字清空**（避免把你自己的同步碼分享出去）。
3. 捷徑列表長按「宥芯同步」→「分享」→「拷貝 iCloud 連結」，貼給 Claude。
4. 你自己的手機重新貼回同步碼，或刪掉重裝一次確認匯入流程正常。

## 客人每天自動執行（App 裡也有寫）

「捷徑」App →「自動化」→「＋」→「時間」→ 22:00、每天 →「立即執行」→ 選「宥芯同步」。
部分 iOS 版本執行時會跳通知，屬正常現象。
